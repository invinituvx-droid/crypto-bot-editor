Как запустить бесплатно

1. Создай бота в Telegram

Напиши @BotFather → /newbot → придумай имя → получи TOKEN

2. Вставь токен в код

В редакторе найди строку BOT_TOKEN = "..." и вставь свой токен.

3. Выбери способ запуска (всё бесплатно)

  • Replit — самый простой
    Создай Python-проект → вставь код → Run. Работает 24/7 на бесплатном тарифе (с ограничениями).
  • PythonAnywhere
    Загрузи файл → создай Always-on task (бесплатный тариф есть).
  • Свой компьютер
    Установи Python → pip install python-telegram-bot requests → запусти файл.
  • Railway / Render
    Бесплатный тариф (с лимитами). Подходит для постоянного хостинга.

4. Нужные библиотеки

pip install python-telegram-bot requests

Важно

  • • Никому не показывай свой BOT_TOKEN
  • • API CoinGecko и Binance — полностью бесплатные, ключ не нужен
  • • Бот работает в режиме long-polling (не нужен HTTPS-сервер)

Как пользоваться

1. Открой вкладку Код — там уже лежит готовый бот.

2. Вставь свой токен от @BotFather.

3. Можешь менять код как хочешь — добавляй команды, меняй тексты, добавляй фишки.

4. Нажми Скачать .py и загрузи файл на Replit / PythonAnywhere / свой ПК.

5. Запусти — бот сразу начнёт отвечать в Telegram.

Всё полностью бесплатно. Никаких подписок.
